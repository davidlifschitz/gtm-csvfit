# CsvFit

Drop an export CSV and the destination headers. Get a file the other site will take. Files never leave the browser.

Ask this answers: [Trying to Import Collection to multiple DB Websites](https://www.reddit.com/r/starwarsunlimited/comments/1vl4pwu/trying_to_import_collection_to_mulitple_db/)

- No account
- No upload
- Cap: 8 MB
- Rearranges columns. Does not guess card names.

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```
